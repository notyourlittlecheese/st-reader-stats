# ST Reader Stats

SillyTavern 的本地阅读统计扩展，提供：

- 当前聊天统计
- 当前角色全部聊天统计
- 全部角色总览与年度热力图
- IndexedDB 增量索引
- Web Worker 后台统计，长聊天不会堵住手机界面
- 无需进入聊天即可从角色下拉框加载角色统计
- 当前聊天通过聊天文件接口读取完整记录，不受前端消息懒加载影响
- 同一角色的分支聊天共享历史自动去重
- 年度、月份和自定义日期范围热力图
- 当前选中 Swipe 汉字数
- 全部 Swipe 去重生成量
- Reroll 次数、活跃天数和聊天明细

## 安装

### 方式一：扩展安装器

将本目录上传到一个 Git 仓库，在 SillyTavern 的“扩展 → 安装扩展”中粘贴仓库地址。

### 方式二：手动安装

把整个 `st-reader-stats` 文件夹复制到：

```text
SillyTavern/data/<你的用户>/extensions/st-reader-stats
```

刷新 SillyTavern。在魔棒菜单中点击“阅读统计”。

## 统计口径

- **选中内容**：每条消息只统计当前 `swipe_id` 指向的内容。
- **Swipe 去重生成**：只统计助手消息的所有 Swipe；完全相同的 Swipe 记零新增，连续重复片段不重复计数。用户发送的文字仍属于“选中内容”，但不属于模型生成量。
- **Reroll**：每条消息按 `swipes.length - 1` 计算。
- **分支去重**：同一角色多个聊天中保留了相同消息节点时，只统计一次；分叉后的新消息分别统计。
- 默认忽略角色开场白。
- 默认移除 `<think>`、`<thinking>` 和 `<reasoning>` 标签中的内容。
- 角色/全局统计目前只包含单人角色聊天，不包含群聊。

重复片段使用重叠字符窗口识别，默认阈值为 12。阈值越小，去重越激进；可在扩展设置中调整。

## v0.4.0 年度排版工作室

v0.4.1：默认两列宫格预览，点击卡片进入编辑，完成编辑回到宫格；新增「导出宫格 PNG」，六页宫格尺寸为 1512×3336，单页与长图导出仍保留。主题色入口保持不变。磨砂增加细颗粒和内高光，并在统计面板打开期间模糊其背后的页面根元素，关闭后自动恢复，避免部分移动主题不渲染 backdrop-filter 时透出文字。

- 年度页有「精工」「杂志」「档案」三套原创纯文字模板，每套含六个不同版式：序章、偏爱、最晚聊天、单日峰值、连续陪伴、真实摘录。没有图床或外部字体服务依赖。
- 点击「编辑排版」选择元素，修改文案、字号、字体、对齐、颜色、宽度和位置；数字以 `{活跃天数}`、`{偏爱角色}`、`{最晚时间}` 等占位符绑定当前统计，不会因排版变成固定数字。长文会缩小字号，极长内容仍需手动缩短或拆页，导出前请检查。
- 电脑拖动，手机长按约 0.3 秒后拖动；选中元素会出现虚线框，靠近中线会吸附。可以调整前后图层、撤销/重做、恢复本页模板、复制或删除页面，最多 12 页。编辑模式的画布区域用于拖动，滚动页面请从画布外操作。
- 背景支持本地 PNG/JPEG/WebP 上传、模糊、遮罩和裁切位置；角色头像从本酒馆读取，支持圆形、圆角和原比例。合并组可以自行选择其中任何一张卡的头像。
- 「导入字体」提供苹方、303、筑紫三个本地槽位，支持 TTF/OTF/WOFF/WOFF2，导入一次后记住。没有导入时使用系统黑体/宋体。用户提供的字体不随公开插件仓库分发，另有个人导入包。
- 字体、背景、每个年份和模板的布局、已选摘录保存在当前浏览器独立的 IndexedDB 中；清空统计索引不会删除作品。换浏览器/设备需要重新导入字体与背景、重新排版，目前分组备份不包含作品素材。
- 点击「换一组真实摘录」时才读取年度偏爱组聊天正文。只取该年角色当前采用的回复，排除已知思考/HTML 标签和重复内容；长段 1–2 条，短句 4–5 条，不足时按实际数量。仅已选中的摘录随作品保存，不缓存所有聊天正文。
- 「最晚聊天」从晚上 18:00 至次日截止时间按跨午夜顺序寻找，可把凌晨截止设为 3–8 点（不含截止时间）；只有日期的消息不参与。使用本设备时区，不是在线时长。首次升级会重新建立分钟级索引。
- 本页导出为 1440×2160 PNG；整份长图宽 720 像素，每页高 1080 像素。图片不含选中框与编辑控件，手机在浏览器下载记录中查看。背景/头像未加载完成时会提示，不会悄悄导出缺图版本。
- 面板顶部「主题色」支持六位 HEX 和色盘，会更新统计卡片、热力图和年度模板。磨砂采用大半径背景模糊与较薄底色；不支持背景模糊的浏览器回退实色以保证可读。
- 分组保存按钮移动到顶部并吸顶，字段改名为「整卡归入哪个组」「此存档单独归组」。

## v0.3.0 分组使用说明

- 「年度总结」可切换年份，展示年度字数、消息数、活跃日、偏爱角色/统计组、单日峰值、凌晨同伴和最长连续活跃天数。凌晨为本设备时区 00:00–04:59，缺少时间的纯日期记录不会计入凌晨；不是在线时长估计。词频暂未加入。
- 「分组与备注」中多张卡填写相同组名即可合并展示。单个存档可指定另一组名，或勾选独立统计；留空则继承整卡分组。保存后自动沿用，组备注修改后自动保存。
- 分组不改角色卡和聊天文件。不同卡之间保留独立计数，同一卡分支继续去重；拆分后的各组独立展示，全局仍去重，因此各组相加可能大于全局。
- 分组设置和备注保存在当前浏览器，可导出 JSON 备份后在另一设备导入。清空索引不会清空这些设置。角色卡或聊天文件改名后需重新指定对应规则。
- 默认跳过酒馆元数据明确标记聊天大小为 0 的卡；未知、当前打开及刚变更的卡仍检查。全局「重新索引」会完整检查所有卡，可找回元数据过期漏掉的存档。旧版酒馆若缺少大小字段，仍需要逐卡检查。
- 升级后首次扫描会重建索引，以补充年度凌晨统计需要的时间字段；原始聊天正文不会复制进索引。

## 隐私与缓存说明

聊天内容不会发送到外部服务。索引保存在当前浏览器的 IndexedDB 中。

缓存指纹由聊天文件大小、消息数和末条消息时间组成。只有指纹变化的聊天会重新读取和计算。
