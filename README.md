# ST Reader Stats

SillyTavern 的本地阅读统计扩展，提供：

- 当前聊天统计
- 当前角色全部聊天统计
- 全部角色总览与年度热力图
- IndexedDB 增量索引
- Web Worker 后台统计，长聊天不会堵住手机界面
- 无需进入聊天即可从角色下拉框加载角色统计
- 当前聊天通过聊天文件接口读取完整记录，不受前端消息懒加载影响
- 同一角色的分支聊天共享历史自动去重
- 年度、月份和自定义日期范围热力图
- 当前选中 Swipe 汉字数
- 全部 Swipe 去重生成量
- Reroll 次数、活跃天数和聊天明细

## 安装

### 方式一：扩展安装器

将本目录上传到一个 Git 仓库，在 SillyTavern 的“扩展 → 安装扩展”中粘贴仓库地址。

### 方式二：手动安装

把整个 `st-reader-stats` 文件夹复制到：

```text
SillyTavern/data/<你的用户>/extensions/st-reader-stats
```

刷新 SillyTavern。在魔棒菜单中点击“阅读统计”。

## 统计口径

- **选中内容**：每条消息只统计当前 `swipe_id` 指向的内容。
- **Swipe 去重生成**：只统计助手消息的所有 Swipe；完全相同的 Swipe 记零新增，连续重复片段不重复计数。用户发送的文字仍属于“选中内容”，但不属于模型生成量。
- **Reroll**：每条消息按 `swipes.length - 1` 计算。
- **分支去重**：同一角色多个聊天中保留了相同消息节点时，只统计一次；分叉后的新消息分别统计。
- 默认忽略角色开场白。
- 默认移除 `<think>`、`<thinking>` 和 `<reasoning>` 标签中的内容。
- 角色/全局统计目前只包含单人角色聊天，不包含群聊。

重复片段使用重叠字符窗口识别，默认阈值为 12。阈值越小，去重越激进；可在扩展设置中调整。

## v0.3.0 年度总结与自定义分组

- 「年度总结」可切换年份，展示年度字数、消息数、活跃日、偏爱角色/统计组、单日峰值、凌晨同伴和最长连续活跃天数。凌晨为本设备时区 00:00–04:59，缺少时间的纯日期记录不会计入凌晨；不是在线时长估计。词频暂未加入。
- 「分组与备注」中多张卡填写相同组名即可合并展示。单个存档可指定另一组名，或勾选独立统计；留空则继承整卡分组。保存后自动沿用，组备注修改后自动保存。
- 分组不改角色卡和聊天文件。不同卡之间保留独立计数，同一卡分支继续去重；拆分后的各组独立展示，全局仍去重，因此各组相加可能大于全局。
- 分组设置和备注保存在当前浏览器，可导出 JSON 备份后在另一设备导入。清空索引不会清空这些设置。角色卡或聊天文件改名后需重新指定对应规则。
- 默认跳过酒馆元数据明确标记聊天大小为 0 的卡；未知、当前打开及刚变更的卡仍检查。全局「重新索引」会完整检查所有卡，可找回元数据过期漏掉的存档。旧版酒馆若缺少大小字段，仍需要逐卡检查。
- 升级后首次扫描会重建索引，以补充年度凌晨统计需要的时间字段；原始聊天正文不会复制进索引。

## 隐私与缓存说明

聊天内容不会发送到外部服务。索引保存在当前浏览器的 IndexedDB 中。

缓存指纹由聊天文件大小、消息数和末条消息时间组成。只有指纹变化的聊天会重新读取和计算。
